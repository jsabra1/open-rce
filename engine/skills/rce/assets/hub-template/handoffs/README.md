# Handoffs

| Command | What it does |
|---|---|
| `/rce push` | Handoff packet of the whole chat, returns a code |
| `/rce pull <code>` | Pick up a packet in another chat |
| `/rce live` / `/rce live <code>` | Open or join a live link |
| `/rce live leave` / `/rce live off` | Leave / close for everyone |

Packets are `<code>_<Topic>.md`. Live links are folders in `live/`. Never delete them.
