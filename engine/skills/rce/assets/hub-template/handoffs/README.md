# Handoffs

| Command | What it does |
|---|---|
| `/rcx push` | Handoff packet of the whole chat, returns a code |
| `/rcx pull <code>` | Pick up a packet in another chat |
| `/rcx live` / `/rcx live <code>` | Open or join a live link |
| `/rcx live leave` / `/rcx live off` | Leave / close for everyone |

Packets are `<code>_<Topic>.md`. Live links are folders in `live/`. Never delete them.
